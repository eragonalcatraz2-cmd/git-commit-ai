# 🤖 git-commit-ai

AI-powered git commit message generator that analyzes your staged changes and suggests meaningful commit messages.

## ✨ Features

- 🧠 Smart analysis of git diffs
- 📝 Automatic commit message generation
- 🎯 Follows conventional commits format
- ⚡ Zero configuration required

## 📦 Installation

```bash
npm install -g git-commit-ai
```

## 🚀 Usage

### Basic usage

```bash
# Stage your changes
git add .

# Generate and commit
git-commit-ai commit
```

## 📝 How it works

1. Analyzes your staged changes
2. Detects file types and change patterns
3. Generates a commit message following conventional commits
4. Asks for your confirmation before committing
